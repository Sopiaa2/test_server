# 메이커 순위표 (MVP 1단계)

한국 인디 메이커의 **검증 지표 순위표**. 의존성 0개(Node 20+ 내장 모듈만), 데이터는 JSON 파일 하나, 화면은 서버 렌더링(JS 없음).

## 실행

```bash
ADMIN_PASSWORD=원하는비밀번호 BASE_URL=http://localhost:3000 npm start
# 테스트
npm test
```

| 환경변수 | 설명 |
|---|---|
| `ADMIN_PASSWORD` | **필수**. 관리자(`/admin`, 아이디 `admin`) 비밀번호. 비우면 관리자 화면이 꺼집니다 |
| `BASE_URL` | 사이트 주소. 등록 완료 화면의 관리 링크에 쓰임 |
| `CONTACT_EMAIL` | 개인정보 처리방침에 표시할 문의 이메일 |
| `DATA_DIR` | 데이터 저장 폴더(기본 `./data`) |
| `TRUST_PROXY` | 호스팅의 프록시 뒤에서 돌릴 때 `1` (속도 제한이 실제 IP 기준이 되도록) |
| `GITHUB_TOKEN` | 선택. GitHub API 호출 한도 상향 |
| `COLLECT_INTERVAL_HOURS` | 자동 수집 주기(기본 6) |

## 사용 흐름

1. 메이커가 `/register` 에서 신청 → **관리 주소(비밀 키 포함)** 를 한 번만 보여줌 (이메일 발송 없음, 비밀번호/로그인 없음)
2. 관리자가 `/admin` 에서 **승인** → 순위표 공개, 자동 수집 시작
3. 메이커가 관리 주소에서 소유권 인증(`/verify-<토큰>.txt` 파일 또는 `<meta name="makerboard-verify">`) → "소유자 인증" 배지
4. 지표 추가: 크롬 웹스토어 / Google Play / npm / GitHub (자동), 월 방문자·사용자 (자가 입력)

## 순위 산식 (`src/ranking.js`)

`종합 = Σ log10(1+값) × 단계 가중치 × 인증 계수` — 자동 확인 1.0, **자가 입력 0.2**, 소유자 인증 1.0 / 미인증 0.5. 지표별 정렬 탭은 해당 지표 값만으로 정렬합니다.

## 보안 요약

- **SSRF** (`src/ssrf.js`): http/https·포트 80/443만, 계정정보 URL 금지, localhost/사설·링크로컬·메타데이터 IP(IPv4/IPv6/매핑 주소) 차단, DNS 결과를 연결 시점에 검사(리바인딩 방지), 리디렉션 매 단계 재검사 + 같은 사이트만 허용, 타임아웃 5초, 응답 크기 상한
- 지표 수집은 **등록 URL에서 식별자만 추출**해 허용 호스트(스토어·npm·GitHub)의 주소를 직접 조립 → 임의 URL 은 가져오지 않음
- 속도 제한: 전체/등록/인증/지표 변경/외부 요청 총량/관리자 로그인 실패 (`src/config.js`)
- CSP(`default-src 'none'`), 자동 이스케이프 템플릿, 관리자 CSRF 토큰, 관리 키는 해시로만 저장
- 개인정보는 이메일만 수집, 공개 화면에 노출하지 않음

## 토스 매출 인증 (확장 지점)

`src/toss.js` 에 인터페이스(`RevenueVerifier`)만 있고 구현은 없습니다. 플래그 `FEATURES.tossRevenue` 는 **코드에 false 로 고정**(환경변수로 켤 수 없음).

## 알아둘 점 (꼭 읽어주세요)

- **무료 호스팅의 저장소 문제**: 이 앱은 파일(`DATA_DIR/data.json`)에 저장합니다. Render 무료 등 *디스크가 휘발되는* 호스팅에서는 재배포/재시작 시 데이터가 사라집니다. 영구 디스크가 있는 곳(무료 VM 등, 조건은 각 서비스에서 직접 확인)에 두거나, `/admin` 의 **백업 내려받기**를 주기적으로 받아 `DATA_DIR/data.json` 으로 복원하세요. 트래픽이 늘면 DB 로 교체를 권장합니다(`src/store.js` 만 바꾸면 됨).
- **스토어 수집은 비공식 페이지 파싱**입니다(크롬 웹스토어·Google Play 는 공식 API 없음). 페이지 구조가 바뀌면 해당 지표만 "수집 실패"가 되고 마지막 성공값이 유지됩니다. 약관상 허용 범위는 운영자가 확인하세요. npm/GitHub 는 공식 API 입니다.
- 서버 1대·메모리 속도 제한 전제입니다(재시작 시 초기화).
- 개인정보 처리방침은 **초안 템플릿**입니다. 운영 전 검토하세요.
- 관리 키를 잃어버린 메이커는 셀프 복구할 수 없습니다(이메일 발송 기능 없음). 필요 시 삭제 후 재등록 안내.
